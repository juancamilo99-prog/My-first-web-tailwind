# 🌐 My First Web with Tailwind CSS

Proyecto práctico de una página web estática desarrollada con **HTML5** y **Tailwind CSS**. Este proyecto fue creado como ejercicio para aprender a maquetar interfaces modernas utilizando clases utilitarias de Tailwind.


## 🛠️ Tecnologías utilizadas

* HTML5
* Tailwind CSS
* CSS Utility Classes
* Git y GitHub

---

## 📚 Objetivos del proyecto

Este proyecto fue realizado con el objetivo de practicar:

* La estructura básica de una página web con HTML.
* El uso de Tailwind CSS para estilos rápidos y responsivos.
* La organización del contenido mediante Flexbox y Grid.
* La personalización de colores, tipografías y espaciados.
* El flujo de trabajo con Git y GitHub.

---

## ✨ Características

* Diseño limpio y moderno.
* Maquetación responsive.
* Uso de utilidades de Tailwind CSS.
* Estructura sencilla y fácil de entender.

---

## ⚙️ Cómo ejecutar el proyecto

1. Clona este repositorio:

```bash
git clone https://github.com/juancamilo99-prog/My-first-web-tailwind.git
```

2. Accede a la carpeta del proyecto:

```bash
cd My-first-web-tailwind
```

3. Abre el archivo `index.html` en tu navegador.
